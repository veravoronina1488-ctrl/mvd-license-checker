# МВД РК - Система проверки водительского удостоверения

Полнофункциональное веб-приложение для проверки и управления водительскими удостоверениями с админ-панелью.

## 🎯 Функционал

- ✅ Поиск водителей по номеру УВ
- ✅ Просмотр информации о водителе
- ✅ История штрафов и нарушений
- ✅ Статус лицензии
- ✅ Админ-панель для управления данными
- ✅ Аутентификация с JWT
- ✅ PostgreSQL база данных

## 🛠️ Стек технологий

**Frontend:** React 18, Tailwind CSS, React Router, Axios
**Backend:** Node.js, Express, PostgreSQL, JWT

## 🚀 Быстрый старт

### Docker
```bash
docker-compose up
```

### Локально
```bash
cd backend && npm install && npm start
cd ../frontend && npm install && npm start
```
